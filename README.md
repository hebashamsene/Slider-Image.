# 🖼️ Image Slider | عرض صور تفاعلي

مشروع واجهة أمامية (Front-End) تفاعلي لعرض مجموعة من الصور بطريقة سلسة وجذابة. يهدف المشروع إلى توفير تجربة مستخدم بسيطة وعصرية للتنقل بين الصور.

---

## 🌟 المميزات (Features)

* ↔️ **تنقل سلس:** أزرار مخصصة للانتقال المباشر للصورة التالية والسابقة (Next / Previous).
* 🔘 **مؤشرات التنقل (Pagination Indicators):** نقاط تنقل سفلية تتيح الانتقال المباشر لأي صورة محددة.
* ⚡ **تأثيرات بصرية ناعمة (Smooth Transitions):** انتقالات حركية مريحة للعين عند التبديل بين العناصر.
* 🔢 **عداد الصور (Counter):** توضيح رقم الصورة الحالية بالنسبة للعدد الإجمالي.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5:** لبناء هيكل الصفحة وعناصر السلايدر.
* **CSS3:** للتنسيق، التصميم المتجاوب، والتأثيرات الحركية (Transitions).
* **JavaScript (Vanilla JS):** للتحكم بمنطق التبديل، الاستجابة للأحداث (Events)، وإدارة الحالة دون مكتبات خارجية.
